# FAZO — ТОРГОВЫЙ ТЕРМИНАЛ

Профессиональный терминал для трейдеров в стиле TradingView:
графики MT5, Binance, Bybit и cTrader, стратегии SMC, Elliott Wave,
TRADING HUB и Trend Following, торговля прямо с графика и встроенный
ИИ-аналитик (Claude, OpenAI, DeepSeek).

## Установка
1. Скачайте последнюю версию в разделе **Releases** справа.
2. Распакуйте архив, например, на Рабочий стол.
3. Запустите `Fazo.exe` и отправьте продавцу «код компьютера».
4. Введите полученный ключ активации.

## Обновления
Fazo обновляется автоматически: при выходе новой версии появится
уведомление «Установить и перезапустить». Ваши настройки, ключи и
лицензия сохраняются.

Проверить вручную: меню «Окна» → «Проверить обновления».
